# Structural Steel Project Delivery & Cost Control Dashboard

## About the Project

I created this project to practice applying project management and project controls concepts using Power BI.

The project is based on a simulated structural steel project. I used the project data to look at costs, labour hours, schedule delays, risks, and change orders and then built a Power BI dashboard to give a project manager a quick view of project performance.

> **Data Note:** The dataset used in this project is simulated and was created for portfolio and learning purposes. It is not based on an actual Imperial Metal project or any confidential company information.

## What I Wanted to Understand

I wanted to answer a few practical project management questions:

- Are we spending more than planned?
- Are actual hours higher than planned?
- Which tasks are behind schedule?
- Which activities have the highest risk?
- How much additional cost could come from change orders?
- What areas should a project manager focus on?

## Tools Used

- Power BI
- DAX
- Excel
- Data Modeling
- Data Analysis

## Key Results

The analysis showed:

- Planned project cost: **$173.7K**
- Actual project cost: **$197.0K**
- Cost variance: **13.4%**
- Labour-hour variance: **12.1%**
- Cumulative task-level schedule delay: **26 days**
- Change-order exposure: **$10.5K**

## What I Found

The project was running above the planned cost and labour hours. The schedule analysis also showed delays across several activities.

The higher-risk areas included material procurement, steel fabrication, delivery, and site installation. These areas would need closer monitoring from the project management team.

There was also $10.5K of change-order exposure, which highlighted the importance of monitoring pending changes and their potential impact on the project budget.

## Project Manager Recommendations

Based on the analysis, I would recommend:

- Monitoring fabrication and installation progress more closely.
- Reviewing labour hours against the project plan regularly.
- Following up early on procurement and material risks.
- Tracking pending change orders and their financial impact.
- Reviewing cost, schedule, and risk information regularly with the project team.
